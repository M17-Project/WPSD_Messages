Old/Unsupported Version of WPSD Detected!

You are running a version of WPSD that is now unsupported.
This means that you had installed WPSD over an existing Pi-Star installation, which is now end-of-life and is not updated any longer.

To continue to receive updates and to take advantage of new WPSD features, you MUST install WPSD using a proper disk image for your hardware. Failing to do this will also result in no one being able to support you if you encounter issues.

This message does not exist once you upgrade using a disk image.
